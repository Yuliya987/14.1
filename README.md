# Проект Введение в ООП

## Описание:

Проект Введение в ООП - это веб-приложение на Python, где созданы продукты и категории продуктов.
Подходит при использовании в онлайн-магазине в дальнейшем.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Yuliya987/14.1.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Создайте новый проект и начните добавлять задачи.
3. Назначайте сроки выполнения и приоритеты для задач, чтобы эффективно управлять проектами.
